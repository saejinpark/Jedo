# 제도 (Jedo, 가제)

아이패드에서 실제 자·삼각자·컴퍼스·원형자를 손으로 다루고 연필로 긋는 감각을 익히는 손제도 앱.
CAD가 아니다. 치수 입력, 도형 자동 생성, 레이어는 없다.

## 지금 상태: 마일스톤 4 (삼각자·원형자·운형자·대나무 곡자·각도기·지우개, 큰 용지와 지도). 컴퍼스 조작 방식은 시안 비교 중

- 종이 질감 위에 연필 7종(HB, B, 2B–6B)으로 긋는다.
- 펜슬만 긋는다. 손가락은 도구를 잡고 컴퍼스 바늘을 꽂는다. 손가락으로 종이를 두드리거나 문지르면 안내가 잠깐 뜬다.
- 필압이 셀수록 굵고 진하며 종이결 골까지 흑연이 들어간다.
- 펜슬을 50° 아래로 눕히면 심의 옆면이 닿아 넓고 옅은 면이 되고 종이결이 더 드러난다.
- 같은 자리를 다시 그으면 진해지지만 경도마다 한계 농도가 있다. 6B는 세게 덧칠하면 검정이 되고, HB는 회색에서 멈춘다.
- 종이결은 "거의 없음"으로 정했다. 빈 종이는 매끈하고 흑연에만 결이 아주 약하게 남는다. 강하게·은은하게 시안과 비교해서 고른 것이다.
- 실행 취소/다시 실행: 화면 버튼, 또는 ⌘Z / ⇧⌘Z.
- 종이는 기기에 붙어 있다. 아이패드를 돌리면 연필꽂이와 버튼만 새 방향으로 돌고 그림은 손 아래 그대로 있다.
- 용지는 화면 긴 변의 2.6배인 정사각형이다(11인치에서 약 60cm). 확대·축소는 없고 언제나 실제 크기다.
- 왼쪽 위 지도에 용지 전체와 그림, 올려 둔 도구의 윤곽, 지금 화면에 보이는 곳(네모)이 나온다. 지도를 누르거나 끌면 그곳으로 화면이 옮겨 간다. 도구는 종이 위에 놓여 있으므로 화면과 함께 옮겨 간다.

### 직선자

- 오른쪽 아래 자 버튼으로 자를 종이 위에 꺼내고 치운다. 20cm 눈금, 폭 3cm의 투명한 자다.
- 한 손가락으로 끌면 미끄러지고, 두 손가락으로 잡으면 미끄러지며 돈다. 늘어나거나 줄지는 않는다.
- 손바닥은 자를 움직이지 않는다. 자를 쥔 채 펜슬로 그을 수 있다.
- 펜슬은 자 밑으로 들어가지 못한다. 자 위를 그으면 선은 가까운 가장자리에 붙는다.
- 가장자리에서 2.5mm 안으로 다가가면 선이 붙고, 4mm 넘게 멀어지면 떨어진다. "끝까지 붙음", "막히기만" 시안과 비교해서 고른 동작이다.
- 선은 튀지 않는다. 붙을 때와 떨어질 때 선이 순간 이동하지 않고, 펜슬이 나아가는 만큼 약 45° 기울기로 가장자리에 다가가거나 멀어진다.
- 펜슬을 처음 댄 자리가 가장자리 근처면 바로 붙는다. 긋는 도중에는 펜슬이 가장자리와 거의 나란히(30° 안) 달릴 때만 붙는다. 가장자리 쪽으로 그었다가 돌아 나오는 선이나 가장자리를 비스듬히 지나가는 선은 그은 그대로 남는다.
- 선의 중심은 심 굵기의 절반만큼 가장자리 바깥에 놓인다. 실제로 심이 자에 닿는 자리다.
- 자 끝을 지나가면 더는 안내하지 않는다.
- 시뮬레이터에서는 마우스가 펜슬이라 한 손가락 끌기는 시험할 수 없다. option을 누른 두 손가락 제스처는 손으로 처리한다.

### 삼각자, 원형자, 운형자, 대나무 곡자, 각도기

- 오른쪽 아래 윗줄 버튼으로 자, 45° 삼각자, 30°·60° 삼각자, 원형자, 운형자, 대나무 곡자, 각도기를 하나씩 꺼내고 치운다. 아랫줄은 컴퍼스, 지우개, 실행 취소, 다시 실행이다. 자와 함께 여러 개를 동시에 올려 둘 수 있다.
- 잡는 법은 자와 같다. 한 손가락으로 끌고, 두 손가락으로 돌린다. 손가락이 닿은 도구가 맨 위로 올라온다.
- 삼각자는 세 변 모두 가장자리 따라 긋기가 된다. 붙고 떨어지는 거리는 자와 같다. 변 끝을 지나면 놓아 준다.
- 삼각자 크기: 45°는 두 변 100mm, 30°·60°는 짧은 변 65mm에 긴 변 약 113mm. 11인치 세로 화면에 들어가도록 실물보다 조금 작게 잡았다.
- 원형자는 140×66mm 판에 지름 3–28mm 구멍 14개가 있다. 구멍 안쪽 가장자리 근처에서 펜슬을 돌리면 선이 구멍 테두리를 따른다. 구멍은 표시 지름보다 0.25mm 크게 뚫려 있어서 선의 가운데가 표시 지름 근처에 온다.
- 원형자의 바깥 네 변도 곧은 가장자리로 쓸 수 있다.
- 운형자는 주황빛 아크릴이다. 넓은 몸통이 한쪽으로 뻗으며 말려 올라가고, 끝으로 갈수록 휨이 꾸준히 급해진다(끝에서 중심선 반지름 18mm). 몸통에는 휘어진 홈이 뚫려 있다. 바깥 둘레 전체와 홈 안쪽 둘레가 모두 가장자리라서, 어느 곡선에 대고 그어도 선이 따라간다.
- 대나무 곡자는 길이 600mm, 폭 22mm다. 거의 곧게 뻗다가 끝쪽 3분의 1에서 대부분 휘어 전체로 약 40° 돈다. 화면보다 길어서 지도로 화면을 옮겨 가며 쓴다. 대나무라 불투명해서 밑의 그림이 가려진다. 볼록한 쪽에 cm 눈금이 있고, 양쪽 긴 변 모두에 대고 그을 수 있다.
- 각도기는 반지름 60mm 반원이다. 밑변 가운데의 중심 표시를 기준으로 돌고, 둥근 가장자리에 바깥쪽 0–180°, 안쪽 180–0° 눈금이 있다. 둥근 가장자리와 밑변 모두에 대고 그을 수 있다.
- 다른 형판들(타원자 등)은 나중에 따로 다룬다.
- 모든 도구는 단단한 판이라 펜슬이 판 위로 올라가지 못한다. 판 위를 그으면 선은 가장 가까운 가장자리로 밀려난다. 원형자 판 위에서도 마찬가지다.
- 도구끼리는 서로 통과한다. 삼각자를 자에 대고 미끄러뜨리는 맞물림은 아직 없다.

### 지우개

- 오른쪽 아래 지우개 버튼으로 들고 내려놓는다. 지우개를 든 동안 손가락으로 문지르면 지워지고, 펜슬은 그대로 긋는다. "펜슬이 지우개" 시안과 비교해서 고른 동작이다.
- 손가락이 움직이기 시작해야 지우기가 시작된다. 그래서 지우개를 든 채로도 손가락을 가만히 누르면 컴퍼스 바늘이 꽂히고, 도구에 닿으면 도구를 잡는다.
- 폭 5mm의 지우개 모서리로 문지르는 셈이다.
- 한 번 문지를 때마다 흑연이 일부만 지워진다. 왔다 갔다 할 때마다 더 지워진다. 세게 누를수록(펜슬일 때) 더 지워진다.
- 종이결 골에 박힌 흑연은 덜 지워져서 진한 선은 흐릿한 자국이 남는다.
- 한 번 문지른 것은 실행 취소 한 번이다.
- 도구 위로도 지울 수 있다. 지우개판(지움 보호판)은 없다.

### 컴퍼스

- 오른쪽 아래 컴퍼스 버튼으로 꺼내고 치운다. 버튼이 켜진 동안 손가락으로 종이를 0.4초 누르고 있으면 그 자리에 바늘이 꽂히고 컴퍼스가 나타난다. 바늘이 빠지면 컴퍼스도 사라진다. (종이에 누워 있는 컴퍼스는 의미가 없다는 피드백으로 없앴다.) 손가락으로 종이를 0.4초 누르고 있으면 컴퍼스가 그 자리로 와서 바늘이 꽂히고 진하게 보인다. 바늘이 빠지면 그 자리에 다시 흐릿하게 눕는다.
- 바늘을 꽂은 손가락이 아직 닿아 있고 컴퍼스로 긋기 전이면, 손가락을 밀어 바늘 자리를 조금씩 옮길 수 있다.
- 펜슬이 닿은 곳까지 다리가 벌어진다. 1.5mm보다 가깝거나 150mm보다 멀면 컴퍼스가 닿지 않아 펜슬이 그냥 긋는다.
- 펜슬을 어디로 움직이든 심은 원 위에 있고, 바늘에서 본 펜슬 방향을 따라 돈다. 바늘 가까이(반지름의 30% 안)로 오면 심은 멈춰 기다린다.
- 컴퍼스 심은 세워져 있어서 펜슬을 눕혀도 옆면 칠이 되지 않는다. 필압은 그대로 따른다.
- 한 번에 한 바퀴 넘게 돌리거나 왔던 길을 1.5mm 넘게 되돌아가면 그 부분은 덧그은 것처럼 진해진다. 여러 바퀴를 돌려도 실행 취소는 한 번이다.
- 조작 방식은 아직 시안이다. 디버그 빌드에서 컴퍼스를 꺼내면 오른쪽 위에 시안 선택이 뜬다.
  - 다리: "닿을 때마다 벌림"(첫 시안)은 펜슬이 닿을 때마다 반지름을 새로 정한다. "벌린 폭 유지"는 직전 반지름에서 1.5mm 안에 닿으면 같은 반지름을 쓰고, 바늘을 다시 꽂아도 다리 폭이 남는다.
  - 바늘: "누르는 동안"(첫 시안)은 손가락을 떼면 바늘이 빠진다. "꽂아 둠"은 손가락을 떼도 남고, 바늘을 짧게 두드리면 빠지며, 다른 곳을 길게 누르면 옮겨 꽂힌다.
- 시뮬레이터에서는 손가락(두 손가락 제스처)과 펜슬(마우스)을 동시에 쓸 수 없어서 "꽂아 둠"으로만 시험할 수 있다.

## 실행

Xcode에서 `Jedo.xcodeproj`를 열고 아이패드(iPadOS 27 이상)를 골라 실행한다.
시뮬레이터에서는 마우스가 펜슬 대신 그린다(필압 0.5 고정, 기울기 없음).

```bash
xcodebuild -project Jedo.xcodeproj -scheme Jedo -destination 'platform=iOS Simulator,name=iPad Pro 11-inch (M5)' test
```

## 구조

- `Jedo/Core/` — UIKit 없는 순수 로직. 단위 테스트 대상이고 맥에서도 컴파일된다.
  - `PencilGrade` 경도표, `PencilDynamics` 필압·기울기 반응, `PressureCurve` 펜슬 force 정규화
  - `DabSpacer` 획을 따라 일정 간격으로 흑연 점을 찍는다
  - `PaperTexture` 이어 붙여도 이음매 없는 종이결 높이맵
  - `GraphiteRaster` 128px 타일 희소 래스터, `DabRasterizer` 점 하나를 래스터에 찍는다
  - `DraftingSheet` 종이 + 진행 중 획 + 예측 끝 + 실행 취소를 묶는다
  - `PendingSampleQueue` 펜슬 필압이 추정치에서 확정치로 바뀔 때까지 샘플을 임시로 그린다
  - `UndoHistory` 메모리 예산(256MB) 안에서 오래된 단계부터 잊는다
  - `ToolShape` 도구 판의 외곽선과 구멍, `EdgeGuide` 어느 도구든 가장자리 따라 긋기
  - `DeskTools` 자·삼각자·원형자·각도기의 모양과 치수, `CurveTools` 운형자·대나무 곡자의 외곽선, `Ruler` 자
  - `Eraser`, `RubTracker` 지우개 문지르기와 되돌아올 때마다 한 번 더 지우기
  - `Compass`, `ArcGuide` 컴퍼스의 바늘·다리 폭, 원호 따라 긋기와 덧긋기 감지
  - `StrokeGuide` 한 획이 기대는 도구(자 가장자리 또는 컴퍼스), `LongPress` 손가락 길게 누르기·두드리기 구분
- `Jedo/Canvas/` — 펜슬 입력을 받는 UIKit 뷰. 종이는 512px 타일 이미지, 흑연은 바뀐 128px 타일만 다시 그린다. `PaperDesk`가 화면 이동과 지도를 맡는다.
- `Jedo/Shell/` — SwiftUI 셸: 연필꽂이, 자·컴퍼스·실행 취소 버튼, 컴퍼스 시안 선택(디버그 빌드만).
- `Tools/Specimen/render.sh` — 경도별 견본(필압 변화, 겹쳐 긋기, 눕혀 칠하기, 해칭, 세게 칠하기)을 맥에서 PNG로 렌더링한다. 아래 손잡이를 바꾼 뒤 결과를 바로 비교할 수 있다.
- `Tools/Icon/render.sh` — 같은 렌더러로 앱 아이콘을 그린다.

## 손맛 조율 손잡이

모두 눈으로 정한 첫 값이다. 실제 아이패드에서 써 보고 바꾼다.

| 무엇 | 어디 |
|---|---|
| 자 가장자리에 붙는 거리·떨어지는 거리 | `EdgeGuideStyle.standard` |
| 붙고 떨어질 때 선이 다가가는 기울기, 도중에 붙으려면 나란해야 하는 각도 | `EdgeGuide.easeRate`, `alongAngleDegrees` |
| 운형자 길이·휨·폭·홈, 대나무 곡자 길이·폭·휨 | `CurveTools` |
| 각도기 크기 | `Protractor` |
| 용지 크기(화면 몇 개 폭), 지도 크기 | `CanvasView.sheetScreens`, `PaperDeskView.minimapSide` |
| 자 길이·폭 | `Ruler.lengthMM`, `widthMM` |
| 삼각자 크기 | `SetSquare.legMM45`, `shortLegMM60` |
| 원형자 크기·구멍 지름·구멍 여유 | `CircleTemplate` |
| 지우개 폭·한 번에 지우는 양·종이결 골이 버티는 정도 | `EraserDynamics` |
| 문지르기로 치는 되돌아감 거리 | `RubTracker` |
| 컴퍼스 최소·최대 반지름, 벌린 폭을 유지하는 거리 | `Compass.minSpreadMM`, `maxSpreadMM`, `keepSpreadMM` |
| 덧긋기로 치는 되돌아감 거리 | `ArcGuide.reverseMM` |
| 바늘을 꽂는 누르기 시간·허용 흔들림, 바늘을 빼는 두드리기 거리 | `LongPress.duration`, `CanvasView.pressSlopMM`, `needleHeadMM` |
| 경도별 선 굵기·한 번 그을 때 농도·한계 농도·종이결 문턱·가장자리 번짐 | `GradeParameters.table` |
| 얼마나 세게 눌러야 최대 필압인지, 가벼운 필압 끌어올림 | `PressureCurve.fullScale`, `gamma` |
| 몇 도부터 심 옆면이 닿는지, 눕혔을 때 얼마나 넓고 옅어지는지 | `PencilDynamics`의 `tiltStartsBelow`, `fullSideBelow`, `sideStretch*`, `sideOpacityDrop`, `sideGrainLift` |
| 필압이 굵기를 얼마나 바꾸는지 | `PencilDynamics.pressureWidening` |
| 종이결의 크기·밀도 | `PaperTexture.bumpsPerPixel`, `bumpRadius` |
| 종이결이 얼마나 드러나는지(빈 종이의 음영, 흑연이 골까지 드는 정도, 심의 거친 정도) | `GrainStyle.standard` |
| 세게 누를 때 종이결 골이 얼마나 메워지는지 | `PencilDynamics.pressureGrain` |

## 아직 안 한 것

- 컴퍼스 조작 방식을 아이패드에서 고른 뒤 시안 선택을 없앤다.
- 자를 따라 한 획 안에서 왔다 갔다 해도 아직 진해지지 않는다. 덧긋기 감지는 컴퍼스와 지우개에만 있다.
- 삼각자를 자에 대고 미끄러뜨리는 도구끼리의 맞물림.
- 렌더링은 Core Graphics(CPU)다. 맥 벤치마크에서 6B를 눕혀 빠르게 칠해도 프레임당 0.4ms 안쪽이라 Metal은 아직 필요 없다.
- 저장/공유, 커리큘럼, AI 기능은 이번 범위 밖이다.
